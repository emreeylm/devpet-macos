# Contributing

Use Xcode/macOS 14+, keep production dependencies minimal, and run `swift test` and `Scripts/build.sh`. Add core regression tests for quota semantics rather than mirroring view implementation. After adding sources regenerate the project with `python3 Scripts/generate-project.py`.

Never invent quota fields or credentials flows. Link upstream primary documentation when updating provider protocols. Keep adapters replaceable and retain explicit missing/stale states. Never log raw authentication or statusline payloads. No user configuration edits without explicit permission.

For visual changes render `--render-gallery`, inspect all twelve characters and all moods, and verify settings at minimum window size in both languages. Preserve accessible control names and Reduce Motion support. Do not replace artwork with emoji or copy illustrations without redistribution rights.
